# NEXUS V15 — Living Constellation

V15 pousse la métaphore du World Model : les entités restent des vignettes rondes, les relations deviennent des trajectoires animées, et le Cube GAÏA agit comme noyau d'observation.

## Interactions
- clic sur une vignette : focus réseau
- OrbitControls : exploration spatiale
- What-if : visualisation d'une propagation sans mutation
- Recentrer / Effacer : retour à l'état stable
- responsive : panneaux simplifiés sur mobile

## Contraintes
- aucune dépendance Base44
- aucune donnée distante requise
- Three.js chargé côté navigateur
- démonstrateur autonome
